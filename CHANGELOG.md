# Changelog

## 0.1.0-rc1 — 2026-11-11

First unofficial preview of AQuA2 Portable, based on Python.

- Windows x64 portable application; no MATLAB or separate Python installation required.
- Preprocessing, event detection, event features and CFU analysis, with stage tabs and Run All.
- English UI, shared parameter presets, polygon regions/landmarks and favorite markers.
- GPU image display and linked 3D volume views with rotation, pan and zoom.
- Manual project saving and configurable tables, overlays, rising maps and view exports.
- Source/executable result comparisons and desktop checks; see [validation](docs/VALIDATION.md).

This preview may contain bugs. Independent coverage of all MATLAB options is incomplete.
